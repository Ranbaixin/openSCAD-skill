# 修改底盒侧壁并验证装配

在仓库根目录使用已安装 `requirements.txt` 的 Python。Windows PowerShell 可直接调用虚拟环境，保留输出目录内的每一次运行。

```powershell
& .\.venv\Scripts\python.exe scripts/verify_assembly.py --wall 3 --out "$env:TEMP\装配 验收"
```

每个 `run-*` 下有 `baseline/`、`variant/`、`diagnostics/` 和 `report.json`。两个版本分别交付 `base.stl`、`lid.stl`，打印坐标的底面均为 Z=0。`reference/pcb.stl` 使用装配坐标，供测量使用。程序打印报告路径；必需项失败、无法判定或未运行均返回非零。两次使用同一 `--out` 会生成两个运行目录。参数 `--model` 可用于另存的同接口 SCAD；模型识别 `part="base"|"lid"|"pcb"` 与数值 `wall`。

| 接口 | 独立验收基准，单位 mm |
|---|---|
| 坐标与外形 | 原点位于底盒外部左前下角，X 向右、Y 向后、Z 向上。底盒从 (0,0,0) 到 (100,60,16)，底厚 2。 |
| 允许变化 | 侧壁由 2 向内增至 3。将基线与指定侧壁带作布尔运算，再与变体测对称差体积。盖和 PCB 也分别比较。 |
| 孔 | 全局 XY 为 (10,10)、(90,10)、(10,50)、(90,50)，孔轴沿 Z，直径 3.2。 |
| 上盖 | 100 × 60 × 2，装配时沿 +Z 平移 16；盖底仅允许接触盒沿。 |
| PCB | 从 (5,5,6) 到 (95,55,7.6)，底面贴四个外径 6 的支柱顶环。侧向留 0.5，板顶上方留 4。 |
| 测量限值 | 长度及径向孔心误差 0.05 mm，实体布尔体积误差 0.01 mm³。非接触区贴合检测层厚 0.10 mm。 |

测量代码在 `scripts/assembly_geometry.py` 中独立定义坐标。截面轮廓给出孔心与最小内切、最大外接直径。底盒取 Z=0.5、1.5、4.5、5.8，上盖取本地 Z=0.25、1、1.75，PCB 取 Z=6.2、6.8、7.4。在底盒 Z=10 的两条中心截线上实测四侧壁厚。贯穿全装配的通规内切直径为 3.15；另外验证孔周指定环带的材料量。

布尔检查使用已导出的 STL。两实体的交叠体积等于两者体积之和减去并集体积。每次先用已知分离、面接触和穿入 0.5 mm³ 的立方体校准，再检查盖、PCB、保留空间和接触区。两件贴合时复核指定接触区以外的净距。正残差超过 0.01 mm³ 表示实体侵入；数值在阈值内表示未检出超阈值重叠。明显负残差、渲染警告、异常退出、缺失产物或无效网格均不能通过。该算法要求每个操作数及并集都有可读的有体积产物，避免依赖不同版本对空 STL 的表示。报告保留命令、诊断、输入和并集实测体积。

截面还覆盖实际 STL 各顶点高度区间的中点和两端内侧，结果中逐孔保存所有深度。四条竖向测线核对 2 mm 底板，支柱段的外轮廓核对 6 mm 外径。孔周环规内径 3.35、外径 4.5，在每件材料区两端各内缩 0.001 mm，整装通规覆盖完整轴向。每个接触面两侧各取 0.05 mm 材料层，各自向指定零件查覆盖。下件无法代替上件填充接触检测体。

验收仅覆盖最终装配姿态与表中指定的四个安装孔。插入轨迹、紧固载荷、打印公差和实物配合需要各自的验证。
