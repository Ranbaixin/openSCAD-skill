# 复杂装配、分件打印与加强设计

用于已有电池盒、托盘、L 形板或支架，需要持续迭代且必须保持孔位、内腔和装配关系的任务。

## 1. 先冻结接口，再画实体

先从原 SCAD 或 STL 提取并记录，不能仅依赖预览图估计：

| 类别 | 必须记录 |
|---|---|
| 坐标系 | X/Y/Z 正方向、原点、各零件中轴面 |
| 外形 | 包围盒、顶面/边缘所在平面、有效壁厚 |
| 孔位 | 每组孔的直径、坐标、孔距、用途、是否必须保留 |
| 内腔 | 开口方向、深度、不得侵入区域 |
| 接口 | 搭接长度、螺钉方向、螺母/沉孔所在侧、打印分件边界 |

使用明确的局部坐标而不是“左、右、前、后”。例如：

```text
电池盒顶面: Z = 46
模型中心面: X = 62.5
M4 孔: X = 45.5 / 79.5, Z = 150
```

每次用户改方向、角度或“上/外侧”时，先用一句话复述其对应的轴与符号；不明确时用 ASCII 草图确认。旋转后尤其要重新确认开口方向，而不能凭视觉猜测。

## 2. 维护约束表和变更日志

将不可改变的要求与可调整的设计变量分开：

```text
不可变: 原底板 12 个孔均需对应；托盘内腔不得有突起；M4 孔保持可用。
可调: 板厚、搭接高度、肋板尺寸、螺钉数量、分件边界。
```

改一个尺寸后，逐项检查它是否影响：

1. 原孔是否重叠、过近或被遮挡；
2. 内腔深度和开口方向；
3. 两件的实际搭接量，而不是仅看名义高度；
4. 输出零件能否独立打印和装配。

若用户要求“完全覆盖顶板”，应复制所有覆盖区域内的原孔位；不要只保留最低数量的安装孔。孔位冲突时，优先级通常为：新接口孔、不可替代的原孔、其余原孔。删除原孔前先明确它确实可移除。

## 3. 参数化与模块边界

按功能拆成可复用模块，避免修改一个部件时意外导出整个装配：

```openscad
use <pcb_tray.scad>;

module m4_base() { /* 全覆盖底板、竖板、定位舌片 */ }
module tray_upper() { /* 托盘、插槽、延长板 */ }
module assembly() {
    color("gray") m4_base();
    color("steelblue") tray_upper();
}
```

- 库文件使用 `use <...>`；仅在需要共享顶层常量时才使用 `include <...>`。
- 将孔径、中心线、角度、壁厚、间隙、搭接长度放在文件顶部。
- 每个可打印件单独调用一个顶层模块；装配预览文件只负责位置与颜色。
- 旧模型保持独立导出行为；新方案创建新文件，避免覆盖已经验证的版本。

## 4. 分件接口：不要只靠两片板贴合

高托盘或长延长板应采用能传递剪力和弯矩的接口：

```text
推荐: 雄榫 + 双剪插槽 + 4 颗螺钉

上件侧板 ┃   ┃        两侧承受剪力
          ┃ 榫 ┃        雄榫提供定位与抗扭
下件侧板 ┃   ┃
           ● ●          至少两排螺钉抵抗转动
```

- 雄榫与插槽保留 XY 装配间隙；FDM 起点可取 `0.2–0.4 mm`，实际值按打印机校准。
- 螺钉不能仅穿过单薄壁。让螺钉穿过两侧耳板/导轨形成双剪，孔阵至少有两行以抵抗转动。
- 螺母位于不可见或外侧时，建立六角螺母槽；若内腔不可有突起，则在内腔侧做沉孔/沉槽，使其表面齐平或凹入。
- 在 SCAD 中把螺钉方向与孔轴显式写出；竖板上的水平孔通常要用 `rotate([90,0,0]) cylinder(...)`，不要默认沿 Z 打孔。

常用起始值（按实际紧固件确认）：

| 紧固件 | 通孔 | 螺母对边 | 常见用途 |
|---|---:|---:|---|
| M2 | 2.4 mm | 4.0 mm | 小型末端面板 |
| M3 | 3.4 mm | 5.5 mm | 可拆卸延长件 |
| M4 | 4.3 mm | 7.0 mm | 主承力接口 |

## 5. 加强：沿受力路径，而不是随机堆料

先判断弯矩根部：长竖板、托盘背板和斜板根部通常是最高风险区。优先顺序：

1. 增加承力板厚和有效搭接高度；
2. 增加接口宽度及双剪导轨；
3. 在不遮挡孔和不侵入内腔的侧面设置三角肋；
4. 再增加螺钉数量或肋板厚度。

肋板应位于真实的受力平面：

- 支撑竖板与底板：用 Y–Z 平面肋；
- 支撑延长竖板与托盘背部：用 X–Z 平面肋；
- 肋板要避开扳手空间、螺钉孔、托盘开口和 PCB 内腔。

在 OpenSCAD 中把肋作为实心三角棱柱或 `hull()` 连接块，并保证与相邻板件有体积重叠；仅面接触会生成不可靠的非流形/分离实体。

## 6. 斜板与末端孔阵

斜板尺寸应在其自身局部平面中定义，再绕指定轴旋转。以 X–Z 平面内的板为例：

```openscad
// 沿 +Z、+Y 延展的斜板；正负号应由预览和坐标表确认
translate([cx, y0, z0])
    rotate([-angle_deg, 0, 0])
        plate_with_holes();
```

孔距“水平/竖直”通常指斜板局部坐标，不是全局 Y/Z 投影。将孔阵定义为局部 X 和局部长度坐标，旋转整个板和孔阵，孔位才会保持居中。更改斜板长度后，重新计算局部孔阵中心，不要沿全局 Z 手工偏移。

斜板与竖板的连接应有连续根部块或足够的搭接，必要时加两侧 X–Z 三角肋；不要让斜板仅与竖板的一条边相接。

## 7. 每轮修改后的验证

每次改方向、孔位、厚度、分件或肋板后，执行以下最小验证：

1. 重新导出每个独立打印件 STL；OpenSCAD 不应报告错误或未定义模块。
2. 导出装配 PNG，从正视、侧视和俯视检查开口、斜向和孔是否被遮挡。
3. 用网格工具检查每个 STL 是 watertight，并记录包围盒与组件数。
4. 对照约束表检查原孔、新孔、中心线、内腔与接口间隙。
5. 对两个分件分别检查：雄榫是否能进入插槽、螺钉孔是否同轴、螺母槽是否可装配。

示例命令：

```powershell
openscad part-base.scad -o output/part-base.stl
openscad part-upper.scad -o output/part-upper.stl
openscad assembly.scad --render --viewall --autocenter `
  --imgsize=1600,1200 -o output/assembly.png
python scripts/inspect_stl.py output/part-base.stl --json
python scripts/inspect_stl.py output/part-upper.stl --json
```

报告结果时区分“已验证的尺寸”和“设计假设”。例如，明确说“上件相对旧顶面增加的可见高度”为多少，并说明是否已经扣除了搭接量。

## 8. 交付清单

- 独立 SCAD：每个打印件一个；原模型不被覆盖。
- 装配 SCAD：显示完整位置关系，可用于 PNG 预览。
- STL：每件一个，命名包含版本或方案。
- 说明：中心面、基准 Z、孔阵、螺钉规格、螺母槽方向、打印朝向和支撑建议。
- 验证：OpenSCAD 导出结果、watertight、包围盒、已知未验证项。
